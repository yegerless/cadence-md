Ты — медицинский эксперт. На основе приведённого фрагмента сгенерируй 1 ФАКТОИДНЫЙ вопрос о реабилитации пациентов.

Требования:
- Вопрос о конкретном методе реабилитации, сроках или показаниях.
- Чёткий короткий ответ из текста.
- Клинически релевантная формулировка.
- Фокус на практических аспектах: когда начинать, какие методы, сколько длится.

Тебе нужно ЗАПОЛНИТЬ ПОЛЯ СХЕМЫ QAResponsePair:
- question — сформулированный тобой клинический вопрос о реабилитации.
  Пример по СМЫСЛУ:
  "Когда следует начинать раннюю реабилитацию у пациентов после геморрагического инсульта?"
- answer — короткий точный ответ из фрагмента своими словами.
  Пример по СМЫСЛУ:
  "Раннюю реабилитацию следует начинать в первые 24–48 часов после стабилизации состояния пациента, при условии отсутствия нарастания неврологического дефицита и стабильности жизненно важных функций."
- context — ТОЧНАЯ ЦИТАТА из фрагмента клинических рекомендаций ниже, которая содержит информацию, подтверждающую ответ (включая сроки/показания/метод).

ТВОЯ ЗАДАЧА:
- Сгенерировать НОВЫЙ question, НОВЫЙ answer и НОВЫЙ context по фрагменту ниже.
- Вернуть ТОЛЬКО ОДИН JSON-объект в формате:
  {{
    "question": "...",
    "answer": "...",
    "context": "..."
  }}
- Не добавлять никакого дополнительного текста до или после JSON (никаких пояснений, комментариев, маркдауна).

ОБЯЗАТЕЛЬНО:
- НЕ копируй пример вопроса и ответа выше, сгенерируй НОВЫЙ вопрос и НОВЫЙ ответ.

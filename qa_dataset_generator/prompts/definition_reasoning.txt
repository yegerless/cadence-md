Ты — медицинский эксперт. На основе приведённого фрагмента клинических рекомендаций сгенерируй 1 вопрос, требующий ЛОГИЧЕСКОГО ВЫВОДА о механизме развития заболевания, факторах риска или классификации.

Требования:
- Ответ должен требовать синтеза информации из нескольких предложений.
- Вопрос требует понимания причинно-следственных связей.
- Формулировка естественная, как у практикующего врача.
- НЕ задавай вопросы типа "Почему важно..." (это риторика, не клиника).

Тебе нужно ЗАПОЛНИТЬ ПОЛЯ СХЕМЫ QAResponsePair:
- question — твой клинический вопрос, который требует логического вывода на основе фрагмента.
  Пример по смыслу (НЕ копируй дословно):
  "Почему артериальная гипертензия считается одним из основных факторов риска геморрагического инсульта?"
- answer — развёрнутый, но чёткий ответ, который объединяет несколько фрагментов текста и объясняет причинно-следственные связи.
  Пример по смыслу (НЕ копируй дословно):
  "Артериальная гипертензия приводит к структурным изменениям стенок артерий (например, гиалинозу и некрозу), что повышает их хрупкость и риск разрыва при повышении давления."
- context — ТОЧНАЯ ЦИТАТА из фрагмента клинических рекомендаций ниже, которая подтверждает ответ (может быть одно или несколько предложений).

ТВОЯ ЗАДАЧА:
- Сгенерировать НОВЫЙ question, НОВЫЙ answer и НОВЫЙ context по фрагменту ниже.
- Вернуть ТОЛЬКО ОДИН JSON-объект в формате:
  {{
    "question": "...",
    "answer": "...",
    "context": "..."
  }}
- Не добавлять никакого дополнительного текста до или после JSON (никаких пояснений, комментариев, маркдауна).

ОБЯЗАТЕЛЬНО:
- НЕ копируй пример вопроса и ответа выше, сгенерируй НОВЫЙ вопрос и НОВЫЙ ответ.
- Вопрос, ответ и цитата должны быть строго основаны на фрагменте ниже.
- Убедись, что context является дословной цитатой из текста.
